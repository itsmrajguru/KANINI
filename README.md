### 🔧 LibraryManagementAPI

> A production-grade **ASP.NET Core Web API** built as part of the internship to demonstrate full backend proficiency on KANINI's stack.

**Tech Stack:**
![.NET](https://img.shields.io/badge/.NET%2010-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![EF Core](https://img.shields.io/badge/EF%20Core%209-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)
![Swagger](https://img.shields.io/badge/Swagger-85EA2D?style=flat-square&logo=swagger&logoColor=black)

**Features:**
- 🔐 **JWT Authentication** — Role-based access control (Admin / Member)
- 📚 **Book Catalog** — Full CRUD with author & category management
- 🔄 **Circulation System** — Issue & return books, track availability in real-time
- 💰 **Fine Engine** — Auto-calculates overdue fines at ₹5/day
- 📊 **Reports & Analytics** — Library-wide statistics endpoints
- 🛡️ **Global Error Middleware** — Clean, consistent JSON error responses

**Architecture:**
```
LibraryManagementAPI/
├── Controllers/      → HTTP endpoint handlers (Auth, Book, Member, Issue, Fine...)
├── Services/         → Business logic layer
├── Interfaces/       → Dependency Injection contracts
├── Models/           → EF Core database entities
├── DTOs/             → API request / response objects
├── Data/             → LibraryDbContext (EF Core)
├── Middleware/       → Global exception handling
├── Helpers/          → JWT token generation
└── Migrations/       → Code-First DB schema versions
```

📖 See the [LibraryManagementAPI README](./Phase%202/LibraryManagementAPI/README.md) for full setup instructions.

### 📰 News2BriefAI

> An intelligent news aggregation & AI summarization platform built on KANINI's React stack.

**Tech Stack:**
![React](https://img.shields.io/badge/React%2018-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white)
