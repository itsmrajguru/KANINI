```text
/* Classes and Objects in C# */

1) Firstly we will talk about the classes and objects in C#
because C# is a pure Object-Oriented Programming language.

Difference between C++ and C# :

1) Calling Methods
   If the method is NON-STATIC

   C++  -> Call using object.
   C#   -> Call using object.

           Student s = new Student();
           s.Display();

2) Static Methods
   If the method is STATIC

   C++  -> Can be called using ClassName.
   C#   -> Can be called using ClassName.

           Student.Display();

           No object is needed.

3) Header Files
   C++  -> Uses #include<iostream>

   C#   -> Uses using System;

4) Namespace
   C++  -> Generally not used for every program.
   C#   -> Every class belongs to a namespace.

5) Console Output
   C++  -> cout << "Hello";

   C#   -> Console.Write("Hello");
            Console.WriteLine("Hello");

6) Console Input
   C++  -> cin >> name;

   C#   -> Console.ReadLine();

7) String
   C++  -> string
   C#   -> string (alias of System.String)

8) Exception Handling
   C++  -> try, catch
   C#   -> try, catch, finally

9) Everything inside a Project
   C++  -> Usually compile one .cpp file.
   C#   -> Entire project is compiled together.

10) Entry Point
    C++ -> Only one main().

    C#  -> Only one Main() in a project.
```
